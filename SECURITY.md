# Security Policy

## Supported versions

The latest release on the `main` branch is supported with security updates.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report it privately through GitHub's security advisory feature:

https://github.com/devlprkhan/universal-data-cleaner/security/advisories/new

Include:

- the affected version;
- a description of the issue;
- reproduction steps;
- any suggested mitigation.

You should receive an acknowledgement as soon as possible. Please allow time
for a fix before public disclosure.
